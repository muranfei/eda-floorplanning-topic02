# Visual System

This is the default visual direction for EDA teaching packages. Adapt it when
the user or source material specifies another system.

## Core palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#151B20` | primary text, borders, dark backgrounds |
| Paper | `#F6F0DC` | main page and slide background |
| Cream | `#FFFAF0` | diagrams, player surfaces |
| Cyan | `#22BFD7` | primary accent, containment |
| Lime | `#B7DF69` | valid state, positive checks |
| Yellow | `#FFC83E` | highlights, callouts |
| Coral | `#F38469` | failures, overlap warnings |
| Purple | `#8275E8` | secondary module color |

Use black outlines on instructional modules. Keep colored fills saturated but
avoid neon glows.

## Typography

- Use `Microsoft YaHei` for bilingual body and heading text.
- Use `Arial Black` for English display headlines and large numerals when
  available.
- Keep slide title text at approximately 32 pt or larger.
- Keep body text at approximately 17 pt or larger.
- Avoid miniature labels and dense footer fragments.

## Video composition

- Warm paper background with subtle grid.
- Bold two-line title in the upper-left.
- One dominant visual action per scene.
- Use module blocks, outlines, and direct labels rather than decorative icons.
- Keep bilingual subtitles in a dark lower band.
- Use the ChipBot mascot as a guide, questioner, or reaction, not a narrator.
- Animate through position, scale, draw-on lines, and state changes.

## Website composition

- Reuse the paper-grid background and module colors.
- Keep a compact sticky header with language switch.
- Give the video player the strongest visual weight.
- Put chapter navigation beside the player on wide screens.
- Use 4-6 concept blocks, then a separate exercise area.
- Use a visible PPT download block with format, page count, and editability.

## Slide composition

- Use one main composition per slide.
- Prefer flat text and native diagrams over repeated UI cards.
- Use an existing video still once on the cover.
- Use editable native rectangles and grid lines for floorplan examples.
- Put detail in speaker notes, not tiny slide footers.
- Use short noun-phrase titles for topic slides and factual takeaway titles for
  result slides.

## Writing

- Keep English and Chinese meanings parallel.
- Use concrete objects and numbers.
- Explain rules with direct verbs.
- Avoid slogan-like phrasing, forced three-part lists, and punctuation-heavy
  dashboards.
- Keep mascot lines short and functional.
